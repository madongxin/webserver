# 请求生命周期

单条请求没有落盘。下面三列是 2026-10-23 09:41–09:56（UTC `2026-10-23T01:41:00Z` 到 `01:56:00Z`）Prometheus `query_range` 的 10 秒窗口最大值，不是某一帧的时间线。P50 / P95 / P99 未采集。

阶段含义：

| 阶段 | 计时结束点 |
|---|---|
| `handler` | Gateway 读回调返回。移动在 `PostPlayerRequest` 入队后就结束，不含邮箱等待 |
| `rpc` | `HandleMove` 或进图编排函数本身。不含邮箱排队，不含 `PushBatch` |
| `reply_queue` | 从应答排进该连接 EventLoop 到回调开始。不含 `TrySendControl`，不含内核写完 |

心跳函数同样只有十几到二十几毫秒。机器人 12 秒超时和真人约 100ms RTT 用的是同一套 Gateway 代码。差别在这条连接前面是否堆着未发出的 AOI，不在心跳是否进了 Session 或 GameDB。
