压测诊断

Move / Heartbeat 回包链、ControlResponseOutbox、GameLogic AOI、4 核竞争和 TCP 发送。计数器曲线用 rate 或 increase，瞬时量直接显示。心跳在网关连接线程内联应答，logic_dispatch_started 保持为 0；状态卡「Heartbeat 当前阶段缺口」不计这一段，图上仍画出。缺系列显示「指标未导出」。单张图查询失败不影响其余图刷新。

业务 · 玩家与 Gateway 流量

Gateway 绑定 = 当前游戏 TCP 上已 Login/Reconnect 的不重复 player_id。Session ONLINE = Redis 会话集合（两台 Session 报同一份，图上取 max 不是 sum；重连宽限内可能仍 ONLINE，即使 TCP 已断）。两条对不上时优先看 Gateway 绑定。

发送队列与回包耗时

发送队列高水位 = 最近 10 秒内，单次写出时看到的应用缓冲加内核未发送字节。回包排队 = 应答从排进连接事件循环到真正 write 的等待。处理 = 网关读到包后在这条连接上花的时间。RPC = 登录、重连、进图、查线、移动在工作线程里的时间。超过 1 秒的阶段会计入慢包，并在网关日志里打 slow pkt；每 10 秒还有一行 sendq window 和 pkt window。
